# 다익스트라 (Dijkstra) — 우선순위 큐 최단경로

> 2026-06-12 스터디 노트 · 언어: Python

하나의 시작점에서 **모든 정점까지의 최단 거리**를 구하는 알고리즘.
**음수 간선이 없을 때** 사용한다 (음수 간선이 있으면 벨만-포드).

---

## 핵심 아이디어

1. `dist` 배열을 무한대(`INF`)로 초기화하고 시작점만 `0`.
2. **최소 힙(우선순위 큐)** 에서 현재까지 거리가 가장 짧은 정점을 꺼낸다.
3. 꺼낸 정점에서 인접 정점으로 가는 거리를 **완화(relax)**: 더 짧아지면 갱신하고 힙에 넣는다.
4. 이미 확정된(더 짧은 거리로 처리된) 정점은 건너뛴다.

그리디하게 "가장 가까운 정점부터 확정"하는 게 핵심. 음수 간선이 없어야 한 번 확정된 거리가 바뀌지 않는다는 보장이 성립한다.

---

## 시간복잡도

- 우선순위 큐 사용: **O(E log V)**
  - 각 간선마다 힙에 push/pop이 일어나고, 힙 연산이 `log V`.
- 인접 행렬 + 단순 배열 구현은 O(V²) — 정점 수가 적고 간선이 빽빽할 때만 유리.
- 대부분의 코테 문제는 희소 그래프 → **힙 버전이 표준**.

---

## 자주 하는 실수

- **방문 배열로만 거를 때 비효율**: `visited`만 쓰지 말고, 힙에서 꺼낸 거리가 `dist`보다 크면 `continue`로 스킵하는 게 정석 (낡은 항목 버리기).
- **INF 초기화 누락** / 도달 불가 정점 출력 처리 (`INF`면 "INF" 출력 등).
- **음수 간선에 다익스트라 사용** → 틀림. 벨만-포드를 써야 함.
- **양방향/단방향 헷갈림**: 문제가 방향 그래프인지 무방향인지 확인하고 간선 추가.
- **`input()` 안 바꿔서 TLE**: `sys.stdin.readline` 필수.
- 힙에 `(거리, 노드)` 순서로 넣기 — 거리가 첫 원소여야 거리 기준 정렬됨.

---

## Python 템플릿

```python
import sys
import heapq

input = sys.stdin.readline
INF = float('inf')

def dijkstra(start, graph, n):
    dist = [INF] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]  # (누적거리, 노드)

    while pq:
        cur_dist, cur = heapq.heappop(pq)
        # 낡은 항목 스킵: 이미 더 짧은 경로로 확정됨
        if cur_dist > dist[cur]:
            continue
        for nxt, weight in graph[cur]:
            nd = cur_dist + weight
            if nd < dist[nxt]:
                dist[nxt] = nd
                heapq.heappush(pq, (nd, nxt))
    return dist
```

## 예제 1 — 백준 1753 최단경로

방향 그래프에서 시작 정점 K로부터 모든 정점까지의 최단 거리. 도달 불가는 `INF` 출력.

```python
import sys
import heapq

input = sys.stdin.readline
INF = float('inf')

def main():
    V, E = map(int, input().split())
    K = int(input())
    graph = [[] for _ in range(V + 1)]
    for _ in range(E):
        u, v, w = map(int, input().split())
        graph[u].append((v, w))  # 방향 그래프

    dist = [INF] * (V + 1)
    dist[K] = 0
    pq = [(0, K)]

    while pq:
        d, cur = heapq.heappop(pq)
        if d > dist[cur]:
            continue
        for nxt, w in graph[cur]:
            nd = d + w
            if nd < dist[nxt]:
                dist[nxt] = nd
                heapq.heappush(pq, (nd, nxt))

    out = []
    for i in range(1, V + 1):
        out.append("INF" if dist[i] == INF else str(dist[i]))
    print('\n'.join(out))

main()
```

**포인트**
- 같은 간선이 여러 번 주어질 수 있음 → 완화 조건(`nd < dist[nxt]`)이 자동으로 처리.
- 출력은 모아서 `'\n'.join` 으로 한 번에 (속도).

## 예제 2 — 백준 1916 최소비용 구하기

도시(정점) N개, 버스(간선) M개. 출발 도시 → 도착 도시의 **최소 비용** 하나만 출력.

```python
import sys
import heapq

input = sys.stdin.readline
INF = float('inf')

def main():
    N = int(input())
    M = int(input())
    graph = [[] for _ in range(N + 1)]
    for _ in range(M):
        u, v, c = map(int, input().split())
        graph[u].append((v, c))
    start, end = map(int, input().split())

    dist = [INF] * (N + 1)
    dist[start] = 0
    pq = [(0, start)]

    while pq:
        d, cur = heapq.heappop(pq)
        if cur == end:          # 목적지 확정 시 조기 종료 가능
            break
        if d > dist[cur]:
            continue
        for nxt, c in graph[cur]:
            nd = d + c
            if nd < dist[nxt]:
                dist[nxt] = nd
                heapq.heappush(pq, (nd, nxt))

    print(dist[end])

main()
```

**포인트**
- 도착 정점이 힙에서 처음 pop되는 순간이 곧 최단 거리 → `break`로 조기 종료 가능.
- 단일 쌍 최단경로지만 다익스트라 한 번으로 충분.

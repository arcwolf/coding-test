## 3. 자료구조 빠른 참조

| 도구 | 핵심 | 시간복잡도 |
|------|------|:---:|
| `deque` | `append`/`appendleft`/`pop`/`popleft` | 양끝 O(1) |
| `heapq` | `heappush`/`heappop` (항상 최솟값) | O(log N) |
| `set` | `in` 검사, `&`/`|`/`-` | O(1) 조회 |
| `dict` | `d.get(k, 0)` 안전 조회 | O(1) 조회 |
| `Counter` | 빈도수 `Counter(s).most_common(1)` | — |

```python
from collections import deque, Counter
import heapq

# 최대 힙: 부호 뒤집기
heapq.heappush(h, -x);  top = -heapq.heappop(h)
# 튜플 힙: 첫 원소 기준 정렬
heapq.heappush(h, (거리, 노드))
# 개수 세기
cnt = {}; cnt[x] = cnt.get(x, 0) + 1
```

## 4. BFS 템플릿 (최단거리는 무조건 이것)

```python
from collections import deque

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

def bfs(sr, sc):
    q = deque([(sr, sc)])
    dist[sr][sc] = 1                 # 시작=1 (visited 겸용)
    while q:
        r, c = q.popleft()           # 앞에서! (FIFO)
        for d in range(4):
            nr, nc = r + dr[d], c + dc[d]
            if 0 <= nr < N and 0 <= nc < M:          # ① 경계 먼저
                if board[nr][nc] == 1 and dist[nr][nc] == 0:  # ② 길 ③ 미방문
                    dist[nr][nc] = dist[r][c] + 1    # 거리 +1
                    q.append((nr, nc))               # ⭐ 넣을 때 방문 표시
```

## 5. DFS 템플릿 (연결요소·경로·백트래킹)

```python
import sys
sys.setrecursionlimit(10 ** 6)

def dfs(r, c):
    visited[r][c] = True             # ⭐ 들어가자마자 표시
    for d in range(4):
        nr, nc = r + dr[d], c + dc[d]
        if 0 <= nr < N and 0 <= nc < M:
            if board[nr][nc] == 1 and not visited[nr][nc]:
                dfs(nr, nc)

# 연결요소(섬) 개수
cnt = 0
for i in range(N):
    for j in range(M):
        if board[i][j] == 1 and not visited[i][j]:
            dfs(i, j); cnt += 1
```

> BFS vs DFS: 큐 `popleft()`(앞) ↔ 스택 `pop()`(뒤). **최단거리=BFS**, 끝까지 탐색=DFS.

### 그래프(인접 리스트) 만들기
```python
graph = [[] for _ in range(N + 1)]   # 1-indexed
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)               # 무방향이면 양쪽
```

## 6. 이분탐색 / 파라메트릭 서치 템플릿

```python
from bisect import bisect_left, bisect_right   # 정렬된 리스트 위치 찾기

# 파라메트릭 서치: "가능?"을 판별하는 is_valid + 경계 탐색
lo, hi, ans = 0, max_val, -1
while lo <= hi:
    mid = (lo + hi) // 2
    if is_valid(mid):
        ans = mid
        lo = mid + 1     # 최댓값 탐색 (최솟값이면 hi = mid - 1)
    else:
        hi = mid - 1     # 최댓값 탐색 (최솟값이면 lo = mid + 1)
print(ans)
```

## 7. 🔥 단골 함정 체크리스트

- [ ] **출력 형식** — 리스트는 `print(*arr)`. `print(arr)`는 거의 오답.
- [ ] **정수 나눗셈** — `x // y` (음수에서 `int(x/y)`와 다름).
- [ ] **2D 초기화** — `[[0]*M for _ in range(N)]`. `[[0]*M]*N`은 행 공유 버그!
- [ ] **문자열 vs 숫자 정렬** — `input().split()`은 전부 문자열. `"10" < "9"` 함정.
- [ ] **BFS/DFS 좌표 변수** — 검사·표시·큐 모두 `nr/nc`로 일치 (오타로 99% 터짐).
- [ ] **방문 표시 타이밍** — BFS는 큐에 **넣을 때**, DFS는 함수 **들어가자마자**.
- [ ] **경계 검사 먼저** — `0 <= nr < N` 을 `board[nr][nc]` 접근보다 앞에 (음수 인덱스 주의).
- [ ] **최단거리는 BFS** — DFS로 최단거리 구하면 틀림.
- [ ] **재귀 한도** — DFS 전에 `sys.setrecursionlimit(10**6)`.
- [ ] **빈 컨테이너 검사** — `heappop`/`popleft` 전에 `if q:` / `if h:`.
- [ ] **문자열 불변** — 글자 바꾸려면 `list(s)` → 수정 → `"".join()`.
- [ ] **`b = a`는 복사 아님** — 참조. 복사는 `a[:]` / `a.copy()` / `list(a)`.

## 8. 시간복잡도 감각 (1초 ≈ 1억 연산)

| N 범위 | 허용 복잡도 | 대표 풀이 |
|--------|------------|-----------|
| N ≤ 10~20 | O(N!) / O(2^N) | 완전탐색·백트래킹·비트마스킹 |
| N ≤ 1,000 | O(N²) | 이중 반복 |
| N ≤ 100,000 | O(N log N) | 정렬·이분탐색·힙 |
| N ≤ 10,000,000 | O(N) | 한 번 스캔·투포인터 |

> N이 10만 넘는데 이중 for를 생각 중이면 → 정렬/해시/이분탐색으로 갈아타라는 신호.

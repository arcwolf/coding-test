# 오늘의 주제: 파이썬 코테 기초

> 언어: **Python**

코딩테스트에서 알고리즘보다 먼저 막히는 "기본기" — 입력을 읽고, 자료를
가공하고, 형식에 맞게 출력하는 흐름을 정리한다. **샘플은 맞는데 제출하면
틀리는** 전형적 함정들을 함께 기록한다.

---

## 1. 입력 받기 (input)

`input()`은 **항상 문자열**을 반환한다. 계산하려면 변환 필요.

```python
n = int(input())                       # 정수 1개
a, b = map(int, input().split())       # 한 줄에 정수 여러 개 → 변수 분배
arr = list(map(int, input().split()))  # 한 줄의 정수들 → 리스트
s = input()                            # 문자열 그대로
```

흐름: **읽고(input) → 쪼개고(split) → 변환하고(map int) → 담기.**

> N줄 입력 패턴 (정석):
> ```python
> data = []
> for _ in range(N):
>     name, age = input().split()
>     data.append((name, int(age)))   # 숫자는 반드시 int 변환!
> ```

## 2. 출력 심화 (print)

```python
print(1, 2, 3)              # 1 2 3   (콤마 → 공백 구분)
print(1, 2, 3, sep="-")     # 1-2-3   (구분자 변경)
print("a", end=" ")         # 줄바꿈 대신 공백 (반복 출력 시)
```

### ⭐ 리스트를 한 줄로 출력 — `*` 언패킹 (unpacking)
```python
arr = [1, 2, 3]
print(arr)      # [1, 2, 3]   ← 대괄호+콤마 = 거의 항상 오답!
print(*arr)     # 1 2 3       ← 정답
print(*arr, sep="\n")        # 세로로 한 줄씩
" ".join(map(str, arr))      # join: 숫자면 str 변환 먼저
```

- **f-string**: `print(f"{n}의 제곱은 {n*n}")`
- **출력 많을 때 속도**: `print("\n".join(result))` 로 한 번에. (수만 줄이면 `print` 반복은 시간초과)

## 3. 리스트 컴프리헨션 (list comprehension)

`for`문으로 리스트 만들기를 한 줄로. **담을 값 → 출처 → (필터)** 순서.

```python
[i * 2 for i in range(5)]                 # [0,2,4,6,8]
[i for i in range(10) if i % 2 == 0]      # 필터: 짝수만 (개수 줄어듦)
["짝" if i%2==0 else "홀" for i in range(5)]  # 변형: if-else는 앞 (개수 유지)
```

- `for` **뒤** `if` = **필터**(거름), 값 자리 `if-else` = **변형**.
- 2차원 입력: `board = [list(map(int, input().split())) for _ in range(N)]`
- 2차원 초기화: `dp = [[0]*M for _ in range(N)]`
  - ⚠️ `[[0]*M]*N` 은 **모든 행이 같은 리스트를 참조**하는 버그!

## 4. 리스트 다루기 (list)

### 인덱싱 / 슬라이싱
```python
arr = [10, 20, 30, 40, 50]
arr[-1]      # 50  (마지막)
arr[1:4]     # [20,30,40]  ← 끝 인덱스 불포함!
arr[-3:]     # [30,40,50]  ← "뒤 3개" = 끝 자리를 비운다
arr[::-1]    # 뒤집기
```

### 자주 쓰는 메서드
```python
arr.append(x)     # 끝에 하나 추가
arr.extend([x,y]) # 펼쳐서 추가 (append는 통째로 들어감)
arr.pop()         # 끝에서 꺼내 반환
20 in arr         # 포함 검사
sum / max / min / len(arr)
```

> ⚠️ `arr.sort()`는 원본을 바꾸고 **None을 반환** → `arr = arr.sort()` 금지.
> ⚠️ `b = a`는 복사가 아니라 **참조(reference)**. 복사는 `a[:]`, `a.copy()`, `list(a)`.

## 5. 정렬 (sorting)

```python
sorted(arr)                  # 새 리스트 반환 (원본 유지) ← 안전
arr.sort()                   # 원본 변경, None 반환
sorted(arr, reverse=True)    # 내림차순
```

### ⭐ 정렬 키 (key) + 람다 함수 (lambda / 익명 함수)
```python
sorted(words, key=len)               # 길이 기준
sorted(nums, key=lambda x: abs(x))   # 절댓값 기준
```
`lambda 매개변수: 반환식` — 이름 없이 즉석 정의하는 **익명 함수**.

### ⭐⭐ 다중 기준 정렬 (튜플 key)
```python
# 나이 오름차순, 같으면 이름 사전순
sorted(data, key=lambda x: (x[1], x[0]))
# 점수 내림차순, 같으면 이름 오름차순 → 숫자에 마이너스
sorted(data, key=lambda x: (-x[1], x[0]))
```
- `key=lambda x: (a, b)` → a 먼저, 같으면 b.
- 기준마다 방향이 다르면 `reverse=True` 대신 **마이너스 트릭**(`-x[1]`).

## 6. 딕셔너리 & 셋 (dict & set)

리스트의 `x in arr`는 전체 탐색(O(N))이지만, dict·set은 **해시 기반이라
거의 즉시(O(1))** 조회한다. "있는지 / 몇 개인지" 문제의 핵심 무기.

### 딕셔너리 (dict) — 키 → 값
```python
d = {"a": 3}
d["a"]            # 조회 (없는 키면 KeyError 💥)
d.get("x", 0)     # 안전 조회: 없으면 기본값 0
d["b"] = 5        # 추가/수정
"a" in d          # 키 존재 검사 (빠름)
for k, v in d.items():  # 키+값 순회
    ...
```

### ⭐ 개수 세기 (counting)
```python
count = {}
for x in items:
    count[x] = count.get(x, 0) + 1   # if/else 없이 한 줄
# 가장 많은 항목: max(count, key=count.get)
```

### 셋 (set) — 중복 없는 모음
```python
set([1,2,2,3])    # {1,2,3}  중복 자동 제거
len(set(arr))     # 서로 다른 값 개수
a & b   # 교집합 / a | b 합집합 / a - b 차집합
```
> ⚠️ 빈 셋은 `set()`. `{}`는 **빈 딕셔너리**다.
> ⚠️ 문자열은 `split()` 없이 `for c in s`로 **글자 단위** 순회 가능. `split()`은 공백 기준 "단어" 분리.

### (참고) Counter
```python
from collections import Counter
Counter("banana").most_common(1)   # [('a', 3)]
```

## 7. 문자열 처리 (string)

### 문자 ↔ 숫자 — `ord` / `chr`
```python
ord('A')   # 65   (글자 → 코드)
chr(65)    # 'A'  (코드 → 글자)
ord('c') - ord('a')        # 2   (a=0 기준 몇 번째)
chr(ord('a') + 2)          # 'c'
```
> 시저 암호류: `chr((ord(c) - ord('A') + k) % 26 + ord('A'))`

### 자주 쓰는 메서드 (모두 **새 문자열 반환** → 재할당 필요)
```python
s.upper() / s.lower()
s.count("l")            # 등장 횟수
s.find("x")             # 위치, 없으면 -1
s.replace("a", "b")     # s = s.replace(...) 로 받아야 반영
s.split(",")            # 구분자 분리
s.strip()               # 양끝 공백/개행 제거
"abc".isalpha() / "12".isdigit() / "a1".isalnum()
```

### ⚠️ 문자열은 불변 (immutable)
```python
s[0] = "x"          # 💥 TypeError
lst = list(s); lst[0] = "x"; s = "".join(lst)   # 정석
```

### 슬라이싱 응용
```python
s == s[::-1]        # 회문(palindrome) 검사
```
> ⚠️ 단어별 뒤집기는 `input().split()` 후 `[w[::-1] for w in words]`.
> 문자열 전체 `[::-1]`은 단어 순서까지 뒤집힌다.

### ⭐ a~z 개수 세기 — 26칸 리스트가 정석
```python
cnts = [0] * 26
for c in word:
    cnts[ord(c) - ord('a')] += 1
print(*cnts)
```
`ord(c) - ord('a')`가 곧 0~25 인덱스. dict보다 빠르고 0도 자동 포함.

## 🔥 오늘 걸린 함정 모음 (핵심 한 줄)

1. **출력 형식** — 리스트는 `print(arr)`(대괄호) ❌ → `print(*arr)` ✅. *(가장 자주 틀림)*
2. **정수 나눗셈** — `int(x/y)` ❌ → `x // y` ✅ (음수에서 결과 다름).
3. **함수 호출** — `input().split`(함수 자체) ❌ → `input().split()`(실행) ✅.
4. **슬라이싱 방향** — `[작은 인덱스 : 큰 인덱스]`, 끝은 불포함. "뒤 N개"는 `arr[-N:]`.
5. **문자열 vs 숫자 정렬** — `input().split()`은 전부 문자열. 숫자 비교 전 `int()` 변환.
   `"10" < "9"` (문자열은 첫 글자 비교) 라서 자리수 섞이면 오답.
6. **문자열 순회** — 글자별로 셀 땐 `split()` 말고 `for c in s`.
7. **출력 변수 확인** — 답을 담은 변수(`ans`)와 실제 출력 변수가 같은지 점검 (`w` vs `w_maxcnt` 혼동).
